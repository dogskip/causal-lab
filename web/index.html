crdt-fuzz

CRDTs converge. That doesn't mean they're correct.

Deterministic fault injection for CRDTs and local-first sync. Run real CRDT code through partitions, drops, duplicates and variable latency, then replay the exact schedule that produced the result. 

npx crdt-fuzz run --target yjs

Interactive demo (Korean, alpha) Bundle viewer

What works today

  • Seeded, virtual-time schedules with partitions, drops, duplicates and variable latency.
  • Convergence and expected-state checks against real Yjs 13.6.27 and the built-in OR-Map.
  • Replayable v2 bundles: the same schedule returns the same receipt.

What is next

  • Lost-write, idempotence and schema checks.
  • A public report of replayable CRDT integration failures.
  • An English-first timeline viewer and an adapter SDK.

Limits

A passing run is not a proof of correctness. The alpha covers Yjs and the built-in OR-Map only; Loro and Automerge are planned. The interactive demo is still Korean-first while the English viewer is built.
